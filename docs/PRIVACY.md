# Privacy and data flow

Conversations, summaries, selections, fingerprints, and review decisions stay in your browser tab. There are no provider calls, analytics, remote fonts, account integrations, or automatic persistence. Exported reports include the full source and summary; review them before sharing. Clicking the GitHub or Buy Me a Coffee link opens that external service.

## Running locally

The development/preview server binds to `127.0.0.1`. Package installation contacts npm to download dependencies. Production assets may be served by any static host you choose; hosting is not configured automatically. A host can log ordinary page requests, so review its policy before using it for sensitive work.
